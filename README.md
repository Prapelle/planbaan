## กติกาสำคัญ

1. **อ่าน/เขียนข้อมูลโครงการผ่าน `tenantDb()` เท่านั้น** ทุกคำสั่งผูก `project_id` ไว้ เปลี่ยนไม่ได้ `tests/guard.test.mts` จะล้มถ้ามี SQL ถึงตารางโครงการที่ไฟล์อื่น
2. **หน้าและแอ็กชันของโครงการต้องเรียก `requireProject()` ก่อนเสมอ** เพื่อหาโครงการจากโดเมนและตรวจสิทธิ์
3. **ทีม PlanBaan ไม่เห็นข้อมูลโครงการ** เว้นแต่ลูกค้าเปิดสิทธิ์ที่ `/support` และทุกการเข้าถึงถูกบันทึกให้ลูกค้าเห็น
4. **บันทึกการใช้งานห้ามมีข้อมูลลูกค้า** ใช้ `ctx.usage(event, meta)` ซึ่งรับเฉพาะชื่อเหตุการณ์และตัวเลข

## หน้าในระบบ

| หน้า | ใครเข้าได้ | ทำอะไร |
|---|---|---|
| `/` (โดเมนหลัก) | ผู้ที่ล็อกอิน | รายชื่อโครงการที่ตัวเองเป็นสมาชิก |
| `/` (โดเมนโครงการ) | สมาชิก / ทีมช่วยเหลือที่ได้รับสิทธิ์ | ภาพรวม |
| `/plots` | ทุกบทบาทดูได้ · เจ้าของ/ผู้จัดการแก้ได้ | ผังแปลง |
| `/leads`, `/leads/[id]` | ทุกบทบาทดูได้ · เจ้าของ/ผู้จัดการ/ฝ่ายขายแก้ได้ | ลูกค้า |
| `/members` | เจ้าของโครงการ | เพิ่ม/นำออกผู้ใช้ และกำหนดบทบาท |
| `/support` | เจ้าของ, ผู้จัดการ | เปิด/ยกเลิกสิทธิ์ทีมช่วยเหลือ และดูบันทึกการเข้าถึง |
| `/platform` | ทีม PlanBaan | สถิติการใช้งานรายโครงการ และสร้างโครงการใหม่ (admin) |
